# 法源依据与制裁计划覆盖核查（步骤 1 核心依据）

> 本文件支撑 us-sanctions-research 的**步骤 1 · 法源依据与制裁计划覆盖核查**。目的：在名单筛查之前，先把"本案可能涉及哪些 OFAC 制裁计划、各自的法源是什么、该计划下有哪些被制裁群体/政权"铺成一张覆盖清单，供合规官审计后续步骤是否**漏查**了某个制裁计划或关系（如也门胡塞武装）。

## 1. 检索链（法源位阶，自上而下）

```
授权制定法（IEEPA / TWEA / NEA）
   └─ 行政令 EO（开启专项计划的开关）
        └─ 31 CFR Chapter V（OFAC 条例，日常检索主战场）
             └─ 制裁计划 / 清单（SDN / Non-SDN / CSL）
                  └─ 该计划下"被制裁群体/政权/实体类型"（designated groups / regimes）
```

检索顺序建议：
1. 先按**地理/行业/行为线索**定"可能涉及哪些计划"（综合制裁 + 专项/主题计划 + 反恐/网络/毒品等横向计划）。
2. 对每个计划抓 **EO + 31 CFR 章节**作为法源依据。
3. 列出该计划下**主要被制裁群体/政权**——这是防漏查的关键：合规官须据此核对"客户/对手方是否与该群体存在任何关系"，即便其名字不在 SDN 上。

## 3. 为什么需要这一步：也门实例（来自用户实战教训）

**情景**：客户与一家中东贸易公司交易，名字不在 SDN 上，常规名单筛查"清除"。但美国对**也门胡塞武装（Ansar Allah）**有单独制裁措施——胡塞于 2024 年被依据 **EO 13224** 列为 SDGT（外国恐怖组织类），且美国设有**也门/胡塞专项制裁计划**。若未做"适用计划覆盖核查"，很容易**漏掉"审核客户是否与该武装组织存在任何关系"这一步**，因为名单上查不到客户名字 ≠ 客户与胡塞无关联。

**本步骤如何防漏**：
1. 步骤 1 据"涉也门/中东"线索，枚举出"也门/胡塞（EO 13224；专项计划）"并列入覆盖清单，标注"须核对该关系"。
2. 合规官据此补一步：审核客户股东/最终受益人/历史交易对手中是否出现胡塞支持网络、也门冲突相关个人。
3. 即便客户名字未列名，若发现其向胡塞提供物资/资金，即落入该计划禁止范围——这正是名单筛查单独无法发现的漏查。

**教训沉淀**：名单筛查（步骤 2）只回答"名字在不在列"；**步骤 1 的覆盖清单回答"还有哪些计划/关系我必须检查"**。两者互补，缺一不可。

## 4. 高频国别深度细化（伊朗 / 也门 / 俄罗斯）

> 以下针对用户最常碰的三个国别，把"法源 → 被制裁群体 → 关系核查清单 → 常见漏查点"展开到可逐条勾选的程度。**凡标注「关系核查」者，即便对手名字不在 SDN 上也必须落实**，这是防漏查的核心。

### 4.1 伊朗 Iran
- **专项计划**：Iranian Sanctions（综合）
- **授权法**：IEEPA
- **核心 EO**：12957、12959、13059、13599、13608、13846、13871（含二级制裁领域）、13902；近年另有 "Operation Economic Outcast"（2026）项下多批列名
- **主要条例**：31 CFR Part 560（ITSR, Iranian Transactions and Sanctions Regulations）
- **配套（非 SDN 伊朗制裁，CAATSA/IFCA 项下）**：31 CFR Part 561（NS-ISR / IFSR，多为**二级制裁**、不冻结资产）
- **关键被制裁群体（须逐项关系核查）**：
  1. 伊朗政府及其分支（含中央银行、国有银行）
  2. 伊朗金融机构（银行、exchange house、虚拟资产服务商）
  3. 能源 sector：NIOC、NPC、石油/天然气开采与贸易链
  4. 航运/造船：IRISL（Islamic Republic of Iran Shipping Lines）及其众多 front company
  5. 航空：Iran Air、Iran Civil Aviation、Mahan Air（涉 IRGC）
  6. 伊斯兰革命卫队 **IRGC**（含 Qods Force，IRGC-QF）及其控制的庞大商业网络
  7. 国防/军工复合体（MODAFL 等）
  8. 受 **EO 13902** 列名的"在伊朗金融/能源/航运/造船/建筑/采矿行业运营"的主体
  9. 受 **50% 规则**穿透的未列名子公司
- **二级制裁高频连接点**：美元清算、美源货品/技术、特定行业（石油、金融、航运）
- **常见漏查点**：
  - 只查 SDN，漏查 561/NS-ISR 项下的二级制裁实体（名字不在 SDN 但涉伊交易仍可能被追）
  - 漏查 IRGC 控制的隐蔽商业网络（front company）
  - 漏查"非美主体"因美元清算/美源投入触发的二级制裁

### 4.2 也门 / 胡塞 Yemen / Houthi
> ⚠️ 这是用户实战踩过的坑，重点展开。名字不在 SDN ≠ 与胡塞无关联。

- **两个并行轨道**：
  - A. 也门专项制裁（Yemen Sanctions）：**EO 13611**，31 CFR Part 543，针对破坏也门和平/安全/稳定的个人/实体
  - B. 反恐 SDGT 轨道：胡塞（**Ansar Allah**）依 **EO 13224** 于 2024 年被列为 SDGT，31 CFR Part 594，资产冻结
- **关键被制裁群体（须关系核查）**：
  1. Ansar Allah（胡塞武装）及其领导层、军事/采购/财政 wing
  2. 为胡塞提供资金/武器/燃料/技术的支持网络（含境外 facilitator）
  3. 涉也门冲突的其他武装/个人（依 13611）
- **关系核查清单（即使对手名字不在 SDN）**：
  - [ ] 对手是否向也门（尤其胡塞控制区）出口燃料、武器、双用物项？
  - [ ] 对手股东 / UBO / 历史交易对手中是否出现胡塞支持网络成员？
  - [ ] 对手是否通过也门港口 / 中转进行受控货物流转？
  - [ ] 是否使用受胡塞控制的港口或代理行？
- **常见漏查点（即用户那次教训）**：
  - 名字不在 SDN ⇒ 误以为"也门无关联" ⇒ 漏审胡塞关系
  - 只做也门专项（543）漏掉胡塞在反恐（594）下的独立列名
  - 把"也门"当成只有一个计划，未意识到胡塞另走 SDGT 轨道

### 4.3 俄罗斯 Russia
- **两个并行轨道**：
  - A. 俄罗斯有害外国活动（**RuHSR**）：**EO 14024**（2021），31 CFR Part 587，覆盖金融、能源、国防、科技等 sector、寡头、国企
  - B. 乌克兰 / 俄相关（**URESR**）：EO 13660 / 13661 / 13662 / 13685 / 14071 等，31 CFR Part 589，覆盖克里米亚、顿涅茨克/卢甘斯克、俄主权债、特定行业禁令
- **关键被制裁群体（须关系核查）**：
  1. 俄主要银行：PSB、VEB、VTB、Sberbank、Otkritie、Novikombank、Sovcombank 等（多家 SDN）
  2. 能源：Gazprom、Rosneft、Transneft 及其交易链
  3. 国防：Rostec、UAC、UEC 等
  4. 寡头与受列名个人（依 14024）
  5. 受 **50% 规则**穿透的未列名子公司（俄企尤其多壳）
  6. 克里米亚相关实体 / 交易
- **二级制裁 / 连接点**：美原产高科技（含 EAR 受控）、美元清算、欧盟/英国协同制裁（注意 **BIS 出口管制线**并行）
- **常见漏查点**：
  - 漏查 589（克里米亚/乌东）与 587（全俄）双轨并行，只查一个
  - 漏查"非 SDN 但受行业禁令（如 14071 禁止对俄新投资/特定服务）"
  - 忽略 BIS 出口管制（Entity List / EAR）与 OFAC 制裁的交叉

### 4.4 朝鲜 North Korea
- **专项计划**：North Korea Sanctions
- **授权法**：IEEPA（部分基于 UN 安理会决议）
- **核心 EO**：13466、13551、13570、13687、13722、13810
- **条例**：31 CFR Part 510（DPRK Sanctions Regulations）
- **关键被制裁群体（须关系核查）**：
  1. 朝鲜政府及 Workers' Party of Korea（朝鲜劳动党）
  2. 朝鲜金融机构（如 Foreign Trade Bank）
  3. 涉及 WMD / 弹道导弹的实体与采购网络
  4. 朝鲜 IT 人员 / 远程外包网络（近年高发：伪装第三国公民承接外包、洗钱）
  5. 朝鲜黑客组织（Lazarus Group 等，亦落于网络计划）
  6. 受 50% 规则穿透的未列名子公司 / 幌子
- **二级制裁 / 连接点**：涉朝军工/网络活动、美元清算
- **常见漏查点**：
  - 漏查"朝鲜 IT 人员"伪装第三国公民承接外包（人才供应链尽调）
  - 漏查涉 WMD 采购网络（含第三国前台）
  - 只查 SDN 漏查 510 项下其他列名类型

### 4.5 叙利亚 Syria
- **专项计划**：Syria Sanctions
- **授权法**：IEEPA（含 CISADA、CAATSA 相关条款）
- **核心 EO**：13338、13894（人权）、13849（CAATSA 相关）
- **条例**：31 CFR Part 542（Syrian Sanctions Regulations）
- **关键被制裁群体（须关系核查）**：
  1. 叙利亚政府及 Bashar al-Assad 政权核心
  2. 叙利亚军方及涉冲突主体
  3. 受列名的叙利亚能源 / 建筑 / 军工实体
  4. 受 50% 规则穿透者
- **⚠️ 政策变动提示**：2025 年起美国逐步取消对叙"支持恐怖主义国家"认定并部分解除制裁，但仍有多实体列名；**须以 OFAC 实时数据核实当前状态**，勿误判"全解除"。
- **常见漏查点**：以为"全面解除"而漏查仍列名实体；忽略 CAATSA 关联制裁。

### 4.6 其他高频综合制裁计划（简要，关系核查逻辑同前）
- **古巴 Cuba**：31 CFR 515，EO 12854 / 13850，全面禁运、少数许可例外；关系核查：古巴政府/国有实体。
- **委内瑞拉 Venezuela**：31 CFR 591，EO 13850；关系核查：马杜罗政权核心、PDVSA、黄金/石油 sector。
- 以上在 §2 索引表已列；凡对手涉该地理/行业，须补"政府/国有实体/受列名个人"关系核查，即便名字不在 SDN。

|---------|------------------|----------------------|----------------------|
| （枚举出的每个计划） | （对应 EO + 31 CFR） | （该计划下列名的主要群体） | □ 是 / □ 否（理由） |
